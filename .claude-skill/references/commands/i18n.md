# Command: `i18n` — Localization, RTL, Modesty & Identity

## Purpose
Everything that changes when the page targets an Arabic (or other RTL)
audience — typography, direction, caption placement, and the two hard
constraints on generated people/product assets. Kept as the last command in
every sequence, matching the PHP tracks' convention of running `i18n` last.

## When to run it
- Always, as the final step before `deploy` — even for an English-only
  build, to confirm `localization.*` is set deliberately rather than left at
  a template default.
- User phrasing: "make this Arabic", "flip to RTL", "add the Arabic
  version", `i18n`.

## What it does
1. Set `html[lang]` and `html[dir]` from `brand.json`'s `localization.*`
   (`defaultLocale`, `rtlLocales`).
2. **Typography**: apply whichever pair is already resolved in
   `brand.json`'s `typography.families.arabicHeading`/`arabicBody` — that
   resolution is `typeface`'s job (`references/commands/typeface.md`,
   `memory/12-arabic-typography.md`), not `i18n`'s. If neither `typeface`
   nor `brand` has set them yet, apply the default: Arabic headings = El
   Messiri, Arabic body = Tajawal. **Never Amiri** for big display text, and
   no manuscript/calligraphic face above ~24px regardless of which pair is
   in use — it reads as calligraphic, not luxury-clean.
3. **Caption placement**: captions over the film stay small, high-contrast,
   and **off-center** — right-aligned in RTL — so they don't fight the
   centered subject. The opening centered title is the one exception.
4. **Modesty (mandatory for Arab/Muslim audiences)**: any woman in a
   people-containing asset must be fully covered — hijab covering the hair,
   conservative long sleeves, no skin beyond face and hands. This clause
   goes into every people-prompt at generation time (`media` command), not
   patched after the fact. Verify by reading the generated image before
   animating it.
5. **Identity preservation**: logo/wordmark/packaging must stay identical
   across every localized asset. Confirm branding placement (product vs.
   packaging) from the reference before regenerating for a locale.
6. Re-run the `voice.doNotUse` grep in the target language if brand.json
   ships a localized voice block.

## Output convention
```
index.html
  <html lang="ar" dir="rtl">   ← or the brand.json-declared default
```

## Checklist
- [ ] `html[lang]`/`html[dir]` match `localization.*`, not left at a
      template default
- [ ] Arabic display type matches the pair resolved by `typeface` (or the
      El Messiri/Tajawal default), never Amiri, never a manuscript face
      above ~24px
- [ ] Film captions are off-center per direction, not centered throughout
- [ ] Every people-containing asset passes the modesty check
- [ ] Product identity unchanged across localized assets
