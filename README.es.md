## ⚡ Inicio Rápido (Quickstart)

```bash
# Instalación e invocación vía NPX
npx @tidyfactor/cli-cinematic
```

O invócalo directamente dentro de tu asistente de IA (*Google Antigravity, Claude Code, Cursor, Codex*):
```text
/tidyfactor-cinematic
```

## 📋 Matriz de Comandos Principales

| Comando | Objetivo y Resultado | Flujo de Trabajo |
|---|---|---|
| `/brief` | Descubrimiento de marca y parámetros cinemáticos | `workflows/brief.md` |
| `/hero` | Diseño de Hero Section de ultra-lujo | `workflows/hero.md` |
| `/film` | Configuración de frame sequence canvas scrubbing | `workflows/film.md` |
| `/transitions` | Transiciones GSAP y scroll suave Lenis | `workflows/transitions.md` |
| `/perf` | Optimización de FPS y WebP sequence | `workflows/perf.md` |
