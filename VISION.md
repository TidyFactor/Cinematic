## TidyFactor-Cinematic — Track Summary

**TidyFactor-Cinematic** is the luxury scroll-driven landing page track within the TidyFactor ecosystem.

It produces a single `index.html` powered by CDN-only libraries (GSAP, Lenis, Tailwind) — zero build step, zero framework, zero bundler.

### How this track fits the TidyFactor vision

| TidyFactor Principle | How Cinematic Delivers It |
|---|---|
| **Structure over Complexity** | One file, CDN-only, no build step — nothing hidden |
| **Content over Code** | `brand.json` is the single source of truth for all identity, copy, and palette |
| **AI Native** | Full `AGENTS.md` + `SKILL.md` — built to be scaffolded by any AI coding agent |
| **Open by Design** | MIT Licensed, published on npm, zero vendor lock-in |
| **Convention over Configuration** | 8 layout templates, sensible defaults, `brand.json` overrides only what's needed |
| **Evolution over Replacement** | Memory-driven architecture — each memory module evolves independently |
