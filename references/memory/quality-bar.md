## 🚫 Non-Negotiable Invariants

1. **Canvas Frame Scrubbing**: Never use `<video>` currentTime scrubbing for product films. Always use canvas frame sequences.
2. **Zero Build Dependency**: Single-file deliverable playable directly via double-click or static web server.
3. **No Amiri Headers**: Never use Amiri for headings larger than 24px (Amiri is a book/body text typeface, not a luxury display face).
