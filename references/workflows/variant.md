# Workflow: variant

Creates an A/B test variant (`index-variant-b.html`) focusing on high-impact conversion hypotheses.

---

## Steps

1. **Formulate Variant Hypothesis**:
   - Pick one variable to test: hook headline, CTA contrast, color theme, or layout order.

2. **Generate Variant HTML**:
   - Duplicate `index.html` as `index-variant-b.html` with the isolated variation applied.

3. **Pre-Emit Self-Critique**:
   - `/* Pre-emit critique: P5 H5 E5 S5 R5 V5 D5 */`

---

## Validation checklist

- [ ] Variant HTML generated with isolated experimental change.
- [ ] Core cinematic engine and responsiveness preserved.
- [ ] Pre-emit critique stamp included.
